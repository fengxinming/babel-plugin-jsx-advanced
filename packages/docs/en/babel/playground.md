# Playground

Write JSX on the left and inspect the compiled output on the right. The sample already covers every built-in directive in both attribute and tag form, and demonstrates how `if` and `for` nest. The **Config** panel above lets you change `prefix`, `locale`, each directive's enabled state, name and `priority`; nothing recompiles until you click **Transform**. If you rename a directive, remember to update the sample code — **Reset sample** restores the original.
